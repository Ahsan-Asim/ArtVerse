# 🎨 ArtVerse

**ArtVerse** is a full-stack web-based platform designed to empower artists and connect them with global art enthusiasts. The system facilitates the showcasing, selling, and commissioning of both digital and traditional artwork, with advanced features like NFT minting, secure transactions, provenance tracking, and personalized user experiences.

## 📌 About the Project

**ArtVerse** serves as a unified ecosystem where artists can display, sell, and manage their artwork portfolios, while buyers and collectors can purchase, review, and commission art pieces. The platform supports NFT creation and secure blockchain-based ownership tracking to ensure authenticity and transparency.

---

## 🌟 Key Features

- 👤 **User Registration & Authentication** (Artist & Buyer roles)
- 🖼️ **Artist Portfolio Management**
- 🔗 **NFT Minting and Sales**
- 🔍 **Advanced Artwork Search** (keywords, categories, image-based)
- 📜 **Ownership/Provenance Tracking**
- 🧾 **Commission Custom Artwork**
- 💬 **Artist Reviews & Ratings**
- 🤖 **AI-Powered Image Classification**
- 🤝 **Smart Contracts for Secure Transactions**
- 💳 **Integrated Secure Payment System**
- 📈 **Artist Analytics & Custom Profiles**

## 💻 Tech Stack

**Frontend:**
- React.js
- HTML5, CSS3
- Bootstrap / TailwindCSS

**Backend:**
- Node.js

**Database:**
- MongoDB

**Blockchain Integration:**

## 📋 System Requirements

### Functional
- Artist registration and artwork management
- Buyer account creation, cart, and purchase options

- High availability and performance

## 🚀 Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/artverse.git
cd artverse

# Install backend dependencies
cd backend
npm install

# Install frontend dependencies
cd ../frontend
npm install

# Start backend and frontend
npm run dev   # Or use concurrently for full-stack startup


Usage
Artists can register, upload artwork, mint NFTs, and track engagement.

Buyers can explore, search, follow artists, and request custom artwork.

Transactions are completed securely using smart contracts and blockchain.

Admin can moderate listings, monitor system, and resolve issues.
