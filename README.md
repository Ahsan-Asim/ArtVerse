<h1>🎨 Artverse - Web3 Art Marketplace</h1>

<p><strong>Artverse</strong> is a decentralized web-based platform where artists and collectors connect to trade digital and traditional artwork. It enables artists to mint and sell NFTs, manage portfolios, and offer custom commissions. Powered by the <strong>MERN stack</strong>, it integrates blockchain (Ethereum + MetaMask) and a Python-based image similarity engine for enhanced art discovery.</p>

<h2>🚀 Features</h2>
<ul>
  <li>User authentication (Signup/Login)</li>
  <li>Artist portfolio creation and management</li>
  <li>Artwork upload and NFT minting using Ethereum blockchain</li>
  <li>Integration with MetaMask for secure transactions</li>
  <li>Image similarity-based artwork search (Python backend)</li>
  <li>Provenance tracking of digital assets</li>
  <li>Commissioned artwork requests and management</li>
  <li>Smart contracts for automated ownership transfer</li>
  <li>Artwork reviews and ratings</li>
</ul>

<h2>🛠️ Technologies Used</h2>
<ul>
  <li><strong>Frontend:</strong> React.js, HTML5, CSS3, Tailwind CSS</li>
  <li><strong>Backend:</strong> Node.js, Express.js</li>
  <li><strong>Database:</strong> MongoDB</li>
  <li><strong>Blockchain:</strong> Ethereum, Solidity, MetaMask, Web3.js</li>
  <li><strong>Image Similarity:</strong> Python, OpenCV, scikit-learn, Flask</li>
</ul>

<h2>📦 Installation Guide</h2>

<h3>1. Clone the Repository</h3>
<pre><code>git clone https://github.com/yourusername/artverse.git</code></pre>

<h3>2. Run Backend (Node.js)</h3>
<pre><code>
cd artverse/backend
npm install
npm start
</code></pre>

<h3>3. Run Frontend (React)</h3>
<pre><code>
cd artverse/frontend
npm install
npm start
</code></pre>

<h3>4. Run Image Similarity Flask App (Python)</h3>
<pre><code>
cd image-similarity-app
pip install -r requirements.txt
python app.py
</code></pre>

<h2>🖼️ NFT & Blockchain Integration</h2>
<ul>
  <li>Artists can mint NFTs using Ethereum smart contracts</li>
  <li>Users can connect MetaMask to handle ETH payments</li>
  <li>Smart contracts manage ownership and provenance</li>
</ul>

<h2>🔍 Image Similarity Module</h2>
<p>A separate Python microservice allows users to upload an image and retrieve visually similar artworks using feature extraction and cosine similarity.</p>

<h2>📈 Use Case Highlights</h2>
<ul>
  <li>Artists mint NFTs for digital art</li>
  <li>Collectors buy, bid, or request custom artworks</li>
  <li>Buyers search artworks by text or image</li>
  <li>All transactions are secured via Ethereum blockchain</li>
</ul>
